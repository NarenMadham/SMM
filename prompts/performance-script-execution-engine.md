3. CORE SCRIPT RULE

The script must contain real substance. That means:

- if the topic is historical, include actual history

  - if the topic is educational, include actual teaching substance

  - if the topic is AI, include actual AI tool, misconception, workflow, or insight

  - if the topic is business, include the actual principle, example, or tension

  - if the topic is commentary, include the exact opinion angle or argument

  - if the topic is story-based, include actual story beats

  - if the topic is meme/remix based, include the actual remix logic

  - if the topic is comparison-based, include the actual comparison

Do not write scripts that are only:

- tone

  - pauses

  - dramatic phrasing

  - vague relatability

  - empty observation

  - broad “nobody talks about this” lines

  - broad “this changes everything” claims without payload The script must clearly be about something specific.

- format suitability

The goal is not blind imitation.

The goal is high-probability performance with creator compatibility.

7. HOOK RULE

The hook must do real work.

The hook must:

- open the actual topic

  - create immediate orientation

  - trigger curiosity, tension, recognition, contradiction, or emotional relevance

  - fit the selected format

  - fit Instagram consumption behavior

  - fit the intended audience reaction

A hook is weak if it is:

- too generic

  - too abstract

  - interesting but misleading

  - emotionally dramatic but content-empty

  - unrelated to the real payoff

Do not write “good sounding” hooks.

Write hooks that correctly open the selected opportunity.

8. PAYOFF RULE

Every script must land clearly.

The ending must:

- complete the idea

  - reward attention

  - reinforce the main point

  - create a satisfying reaction

  - optionally lead to save/share/comment behavior if appropriate

  - avoid weak fade-outs

Do not let the script end in vagueness.

Do not let the script front-load all the energy and collapse at the end. Strong payoff discipline is required.

9. SCRIPT STRUCTURE RULE

For short-form scripts, structure with purpose. A strong short-form structure usually includes:

- hook

  - setup / framing

  - core explanation / contrast / progression

  - proof, example, or key turn

  - payoff / conclusion

For carousel scripts, structure with slide intent. A strong carousel usually includes:

- opening claim or tension

  - context or mistake

  - proof / breakdown / examples

  - reframe or insight

  - closing takeaway or save-worthy ending

For storytelling scripts, structure with narrative control. A strong story structure usually includes:

- curiosity opening

  - context

  - turning point

  - consequence

  - takeaway or twist

Do not force one template onto every opportunity.

Use the structure that best fits the chosen format and idea.

The script must not drift from the selected priority concept.
