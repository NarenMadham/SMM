Every single script produced here must meet all of the following standards:

▸ Substance

- The script must contain real, actual content — real facts, real examples, real tension, real story, real comparison

- Scripts that are only tone, pauses, and dramatic language without payload are rejected

- The script must clearly be ABOUT something specific that a viewer will walk away having learned, felt, or understood

## The Viral Proof Block — Mandatory for Every Script

This is the most important addition in Prompt 6. Every script must be followed immediately by a Viral Proof Block. This is not optional. The Viral Proof Block must contain all six of the following elements:
▸ Element 1 — Pattern Match

Which specific repeating content pattern from Prompt 2's research does this script use? Name it. Describe exactly how this script repeats or adapts that pattern.

▸ Element 2 — Audience Psychology Trigger

Which specific psychological mechanism is this script activating in the audience? Choose from and explain one or more of the followin

- Curiosity gap — the viewer needs to know how this ends

- Identity resonance — the viewer sees themselves in this content

- Social currency — the viewer will look smart or aware by sharing this

- Validation — the viewer's existing belief or frustration is confirmed

- Surprise or contradiction — what the viewer assumed is being challenged

- FOMO — the viewer feels they are missing something important

- Debate trigger — the viewer disagrees and must comment

- Save-worthy utility — the viewer needs to keep this for later

Do not just name the trigger. Explain exactly how this script activates it.

▸ Element 3 — Comparable Proof

Name a specific real content example from the accounts analyzed in Prompt 2 that performed well using a similar angle, hook, or forma

▸ Element 4 — Instagram Algorithm Signal

Which specific Instagram performance signal is this script designed to generate? Be precise. Choose from:

- Watch time completion — the script is structured so viewers watch it fully

- Share behavior — the content gives viewers a strong reason to send it to someone

- Save behavior — the content is useful or valuable enough to revisit

- Comment behavior — the content creates a reaction people need to express

- Profile visit — the content creates enough curiosity about the creator that viewers tap the profile

- Rewatch behavior — the script has enough density that a second watch is rewarding

Explain specifically why this script will generate that signal — not in general terms, but based on what is actually in the script.

▸ Element 5 — Follower Growth Mechanism

Explain specifically why this piece of content is likely to bring new followers, not just views. What about this script makes a viewe

- It signals the creator knows something the viewer wants more of

- It creates a desire for the next part or a series

- It positions the creator as a trusted authority in the niche

- It creates strong niche identity so the right audience self-selects

- It creates enough conversation that new audiences find it through comments or shares

▸ Element 6 — Confidence Assessment

Based on all the above, give an honest confidence rating:

- High Confidence — strong pattern match, clear psychology, proven comparable, obvious algorithm signal

- Medium-High Confidence — strong in most areas, one element slightly uncertain

- Medium Confidence — good potential but one meaningful risk factor exists
